DirectRenderPipeline

An alternative render pipeline that applies output processing directly in material shaders. This avoids the intermediate framebuffer and output pass used by Renderer, but changes blending and is not compatible with materials that sample the framebuffer, such as transmissive materials.

Note: This module can only be used with WebGPURenderer.

Code Example

const renderPipeline = new DirectRenderPipeline( renderer );
renderPipeline.render( scene, camera );

Constructor
