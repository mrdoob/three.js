# Source

### new Source( data : any )

Constructs a new texture source.

**data**

The data definition of a texture.

Default is `null`.

**Deprecated:** since r186. Use [TextureSource](TextureSource.html) instead. \`Source\` has been renamed to \`TextureSource\`.

## Properties

### .isSource : boolean (readonly)

This flag can be used for type testing.

Default is `true`.

**Deprecated:** since r186. Use [TextureSource#isTextureSource](TextureSource.html#isTextureSource) instead.
