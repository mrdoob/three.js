# Lightmapped Cornell Box

A procedural Cornell box with baked indirect lighting using the draft
`KHR_lightmap` extension and a ceiling point light using `KHR_lights_punctual`.

Created with `webgpu_lightmap_baking.html`. Uses glTF 2.0 and a shared
1024 × 1024 linear lightmap atlas on `TEXCOORD_1`.

No external models or textures. Provided under the repository's MIT license.
